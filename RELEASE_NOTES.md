# Glaude 0.1.0

## New

- One hotkey (Ctrl+`, the key above Tab) opens your apps in a panel over the dimmed game. The same key takes you back, and the game gets the keyboard and mouse again on its own.
- A strip along the top of the panel switches between your apps with a click: T3 Code, Claude, Chrome, File Explorer, Discord or any program.
- Pick a running app or browse for a program in Settings, then rename, reorder or remove apps.
- An app that is already open, even hidden in the tray, is shown in its own window. Glaude only starts an app that is not open at all.
- Each app goes back to the exact place and size it had on your desktop when you switch away or close the overlay. Moves happen out of sight, so nothing flashes.
- The hotkey follows key position, so it works on UK and US keyboards alike. Rebind it in Settings by pressing the new keys.
- Updates from GitHub releases: Glaude checks at start and every few hours, downloads in the background, and installs when you press Install or when you quit. Settings shows the release notes.
- Settings: hotkey, dim level, apps, updates and an About section, all applied as you change them.
