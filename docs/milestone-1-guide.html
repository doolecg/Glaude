Milestone 1 "Proof"

State: In progress: approved 2026-10-28

Read this first
  • Goal: prove the loop works. The hotkey opens Windows Terminal in a panel over a dimmed borderless game, and pressing it again returns focus to the game, 20 times in a row.
  • Out of scope: several apps, the rail, switch keys, presets for Claude, T3 Code and OpenCode, attaching to a running app, the updater and About page (all milestone 2 in the bible), and anything in the idea map.
  • To change anything, write in the notes box under it, press Copy my notes, and paste to Claude.

1. Parts

  • Tray app: Glaude runs from the tray and has a Settings window opened from the tray icon.
  • Hotkey: Ctrl+` by default, registered with tauri-plugin-global-shortcut. Pressed once it opens the overlay, pressed again it closes it.
  • Shade: a borderless, transparent, always-on-top window over the game's monitor, dimmed to 72% by default. A click on the dim closes the overlay. No fades: it cuts in and out at once.
  • One app: Windows Terminal is started on first open, found by its first top-level window, and parked when closed. Parked means moved off-screen and hidden (SW_HIDE), so it leaves no taskbar button. On open it moves to the panel (the monitor minus 50px on every side), goes above the shade and takes focus.
  • Focus handback: on open Glaude remembers the foreground window (the game). On close it parks the app, hides the shade and gives the foreground back to the game, so the game's mouse lock returns on its own.
  • Settings: hotkey, the one app (path and arguments), and dim level. Applied live and saved on change.

2. Questions for doolecg

All four questions from the design are settled, with the recommended answers, on 2026-10-28.

  1. Default hotkey? Settled: Ctrl+`. Free in games and in all four apps.
  2. Dim level? Settled: 72%. The game stays readable as context, the panel stands out.
  3. Start the apps when Glaude starts, or on first open? Settled: on first open. Nothing runs that you did not ask for.
  4. Is "Glaude" the shipped name? Settled: yes. The About page spells it out once.

3. How to test each step

Step 1: run the app

  1. In a terminal in E:\REPOS\AI TOOLS\Glaude, run npm install once, then npm run dev. Or press the Dev Run config in IntelliJ.
  2. A Glaude icon appears in the tray. No window opens; left-click the icon for Settings, right-click for the menu.

Test steps for each later step are added here as it is built.

4. Review checklist

  • With a game in borderless window, press Ctrl+`. The game dims to about a quarter of its brightness and Windows Terminal fills the screen except a 50px margin all round.
  • Type a command in Terminal. It appears at once, with no click needed.
  • Press Ctrl+` again. The panel goes, the game is back in front and its mouse lock works without a click.
  • Click the dimmed margin instead of the hotkey. It closes the same way.
  • Check: open Terminal over the borderless game 20 times in a row and type a command each time. No focus is left on the wrong window and there is no visible flicker.
  • No Terminal button appears in the taskbar while the panel is closed.
  • Change the hotkey and the dim level in Settings. Both apply straight away and survive a restart of Glaude.
  • Try a game in true exclusive fullscreen. The panel does not show over it; this is the stated limit, not a bug.
